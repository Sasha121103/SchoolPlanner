# Школьный Планировщик
 
Десктопное приложение для автоматизации управления учебным процессом в школе, с особым акцентом на адаптацию для **коррекционных учреждений** (ФАОП, шкала трудности предметов, специальные коррекционные предметы).
 
> Выпускная квалификационная работа. Автор: Дроздов Александр Вячеславович, группа БВ311.
 
## О проекте
 
Готовые системы («1С:Образование», «Сетевой город. Образование», «Аверс: Управление школой», «СКБ Контур. Школа») либо слишком дороги и громоздки, либо не учитывают специфику коррекционного образования: индивидуальные учебные планы, щадящий режим нагрузки, особые предметы («Развитие речи», «Адаптивная физическая культура» и др.).
 
**Школьный Планировщик** закрывает эту нишу — гибкая, доступная система, объединяющая учебные планы, расписание, электронный журнал и конструктор уроков в едином решении.
 
## Возможности
 
- 🔐 **Аутентификация и роли** — «Администратор» (УВР) и «Учитель» с разграничением прав на уровне интерфейса
- 📘 **Учебные планы** — вариативные планы по разным программам ФАОП, шкала трудности предметов по классам
- 📅 **Расписание** — ручное и автоматическое составление, фильтрация, утверждение, экспорт в PDF
- 🧠 **Автогенерация расписания** — алгоритм распределяет уроки с учётом сложности предметов, нагрузки учителей и занятости кабинетов (см. [алгоритм](#алгоритм-генерации-расписания))
- 📝 **Конструктор уроков** — планы-конспекты с задачами и этапами, прикрепление файлов ФГОС, рабочий процесс «черновик → на проверке → утверждено / на доработку»
- 📊 **Электронный журнал** — оценки, посещаемость, автоматический подсчёт статистики, полный аудит изменений (кто, когда, что изменил)
- ⚙️ **Панель управления** — справочники (учителя, классы, кабинеты, предметы), экспорт отчётов в PDF/CSV

## Алгоритм генерации расписания
 
1. Загрузка учебного плана класса → формирование списка необходимых уроков
2. Классификация по сложности: тяжёлые предметы (7–10 баллов) — вторник–четверг, лёгкие (1–4) — понедельник/пятница, средние — оставшиеся слоты
3. Подбор учителя по предмету с учётом максимальной нагрузки и свободного кабинета
4. Заполнение пустых слотов уроками «Классный час»
Учёт шкалы трудности предметов и специфики адаптированных программ — научная новизна работы.
 
## База данных
 
25 таблиц, спроектированных с учётом нормальных форм (в ER-модели документации — 20 ключевых таблиц). Ключевые механизмы целостности: внешние ключи, каскадное удаление, уникальные ограничения, триггеры (например, `tr_subjects_after_insert` автоматически создаёт запись в `subject_difficulty` при добавлении предмета) и индексы на часто используемых полях.
 
## Установка и запуск
 
1. Установите [XAMPP](https://www.apachefriends.org/) (или отдельно MySQL) и разверните сервер
2. Импортируйте схему базы данных через phpMyAdmin
3. Клонируйте репозиторий и откройте решение в Visual Studio
4. Укажите строку подключения к MySQL (сервер, порт, БД, пользователь, пароль) в конфигурации `DbHelper`
5. Соберите и запустите проект — при первом запуске автоматически создаются демонстрационные учебные планы и шкала трудности предметов
6. Войдите под одной из тестовых учётных записей, указанных на странице входа
## Тестирование
 
| Вид тестирования | Что проверялось |
|---|---|
| Модульное | операции с БД, аутентификация, алгоритм генерации, конструктор уроков, журнал |

| Функциональное | все сценарии — от создания плана до формирования отчётов |
| UI | навигация, отображение данных, реакция на ошибки ввода |
 
**Производительность:** отклик приложения — менее 1 секунды для большинства операций, генерация расписания для всех классов — не более 5 секунд, поиск по расписанию — миллисекунды.
